# PRD 转操作手册 (doc-manual)

本 Skill 用于帮助产品经理 (PM) 将 PRD 文档快速、结构化地转化为面向用户的产品操作手册。

## 一、如何安装 Skill

1. **获取代码**：首先从 GitHub 下载或克隆本 Skill 的代码到本地。
2. **移动目录**：使用你常用的 IDE（如 VSCode）、OpenClaw 等工具，或直接在系统自带的终端/访达中操作。
3. **安装 Skill**：将整个 `prd-to-manual` 文件夹移动或拷贝到你的 skills 目录中；或者你也可以直接向 AI 助手发送此 prompt 指令完成自动安装：`请帮我从 GitHub 仓库 https://github.com/zuo1999/prd-to-manual 下载这个 skill，并将代码克隆到我的skills目录
4. **生效**：重新启动或刷新你的 AI 助手，系统会自动识别并加载名为 `doc-manual` 的 skill。

## 二、如何导入 PRD

在对话框中输入唤醒词 `/doc:manual` 并带上 PRD 的来源即可。支持三种导入方式：

1. **直接启动向导（无参数）：**
   ```text
   /doc:manual
   ```
   AI 会主动提示并引导你提供飞书链接或本地文件路径。

2. **从飞书文档导入：**
   ```text
   /doc:manual https://你的飞书文档链接
   ```
   *注意：使用飞书链接需要你在本地安装并授权 `lark-cli`。如果没有安装，AI 在执行时会提示并引导你通过 `brew install lark-cli` 和 `lark-cli auth login` 完成配置。*

3. **从本地文件导入（支持 .md 或 .docx）：**
   ```text
   /doc:manual /Users/mac/Documents/my_prd.docx
   ```

## 三、测试样例 Demo

你可以新建一个简单的 `demo_prd.md` 文件，将以下内容复制进去进行测试：

```markdown
# 演示系统 PRD

## 系统菜单
1. 用户管理
2. 订单管理

## 详细功能需求
### 1. 用户管理
- 功能点说明：新增用户。
- 功能入口：首页 -> 用户管理。
- 交互逻辑：点击“新增”按钮，弹出表单填写用户名和密码，点击保存。需要[📸 截图：新增用户弹窗]。
- 权限要求：仅管理员可见。
```

将该文件保存后，向 AI 发送：
`/doc:manual /你的保存路径/demo_prd.md`
随后根据 AI 的提示，选择“详细编写”等处理方式即可体验自动生成。

## 四、输出示例

AI 最终会在当前工作区下的 `projects/manuals/` 目录中生成类似如下格式的操作手册 Markdown 文件：

```markdown
### 1.1 用户管理

◆ **新增用户**

功能入口：首页 → 用户管理

支持在系统中创建新的用户账号。

操作步骤

step 1：点击“新增”按钮，弹出表单
step 2：填写用户名和密码
step 3：点击保存

[📸 截图：新增用户弹窗]

注意事项：仅管理员可进行新增操作
```

## 五、模板不适用时，可以提供新的模板

如果你发现默认生成的手册排版格式或者内容结构不符合你们公司的规范，你可以非常方便地通过提供新的模板来进行替换或调整：

1. **直接修改默认模板：**
   在 `prd-to-manual` 目录下有一个模板文件：`templates/menu-section.md`。AI 生成的每个菜单章节都会严格遵循此模板排版。你可以直接用文本编辑器打开它，按需增删标题、调整占位符或修改排版结构。

2. **提供全新的模板文件：**
   如果你有自己现成的 Markdown 格式的手册模板，你可以直接将其替换掉 `templates/menu-section.md` 文件；或者在对话时直接通过 Prompt 告诉 AI：“请使用我提供的这个新模板（附上文件路径或内容）来生成操作手册”。

3. **修改生成逻辑 (SKILL.md)：**
   如果不仅是排版，连目录大纲的提取逻辑都需要改变，你可以打开 `SKILL.md` 文件。里面所有的指导逻辑均采用自然语言描述，你只需要像给人类提要求一样，在 `SKILL.md` 中把旧的提取规则直接改写成你的新要求即可。
